= User Story

== Purpose

A *User Story* represents the smallest user‑centered unit of value within a Feature.  
It describes a specific user goal, expressed in natural language, and defines what the user wants to achieve — not how it is implemented.

User Stories break down a Feature into independently valuable, deliverable slices that fit within a single sprint.

- Capture a single, clear user goal.
- Express value from the user’s perspective.
- Provide a basis for estimation, planning, and slicing.
- Serve as the parent structure for Use Cases.

== Core Entities

- Use Cases
- Version

== Attributes

- `title`: A short, descriptive summary of the user goal.
- `as_a`: The user role initiating the action.
- `i_want`: The specific action or capability the user needs.
- `so_that`: The value or outcome the user gains.
- `description`: Additional context or clarification of the user goal.
- `status`: The current lifecycle state. Possible statuses:
    - Draft
    - Refinement
    - Ready
    - In Progress
    - Validation
    - Blocked
    - Done
- `started_at`: When work on this User Story began.

== Relationships

- 1 Feature → N User Stories
- 1 User Story → N Use Cases
- 1 User Story → 1 Version

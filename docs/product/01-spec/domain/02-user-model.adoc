= User Domain Model

The *User* represents an individual who belongs to Organization(s).  
Users authenticate, receive invitations, join teams, and participate in products.

== Attributes

[horizontal]
Name:: The full name of the user.
Email:: The unique email address used for authentication and communication.
Role:: The role(s) assigned to the user within the Organization, determining their permissions and access levels.
State:: The current state of the user account.
Created At:: The timestamp when the user account was created.

== Invariants
- A user must have a unique email address.
- A user must have a valid state.
- A Deactivated user cannot be assigned to Teams or Products.
- Every user gets the Standard User role by default when they join an Organization.
- Every data and references are deleted when a user is deleted.

== Relationships
- N Users -> N Organizations
- N Users -> N Teams
- N Users -> N Products
- N Users -> 1 Role

== Lifecycle
Invited -> Active -> Deactivated/Deleted
